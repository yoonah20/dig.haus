# 16일의 일기 — dig.haus 만든 기록

2026년 4월 14일부터 29일까지. 본업이 예능 PD인 한 사람이 vinyl 컬렉터로
17년 살아온 자기 디깅 워크플로우를 웹사이트로 옮기는 동안 매일 무슨
일이 있었는지에 대한 기록. 나중에 잊을까봐 남긴다.

---

## Day 0 — 4월 14일 (화)

본격적으로 시작한 첫 날. claude.ai에서 새 대화를 켜고 "베테랑 앱 개발
프로젝트 매니저이자 기획자가 되어달라"로 시작했다. 처음엔 vinyl
최저가 비교 앱을 만들고 싶다고 말했는데, Claude가 솔직하게 "그건 ToS,
Cloudflare, 운송비 변수 때문에 거의 불가능하다"고 잘라줬다. 좋은
신호였다 — 무리한 방향이라고 빨리 말해주는 사람이 있어야 시간 안
까먹는다.

두 번째 시도는 리뷰 모음 + 한국어 요약 앱이었다. Archspire의 *Too
Fast to Die* 발매 3일 만에 14개 사이트에서 리뷰가 나오는 걸 같이
확인하고 나서 "이건 되겠다" 싶었다. 그러다 내가 vinyl 15,000장
컬렉터라는 얘기를 흘렸고, 거기서 모든 게 다시 짜였다. 단순 리뷰
aggregator가 아니라, 내가 매주 하는 디깅의 흐름 — sputnikmusic에서
앨범 발견 → 리뷰 + vinyl 가격 확인 → 비슷한 아티스트로 디깅 이어가기
→ 구매처 링크 저장 — 이걸 한 페이지에 다 올린 사이트.

3-phase 플랜도 이날 정해졌다. Phase 1 정보 허브, Phase 2 개인화 (위시
리스트 / 컬렉션 / 저장된 구매처), Phase 3 커뮤니티 (디깅 일기 / 추천
upvote / 앨범 DNA 마인드맵). 16일 뒤에 보면 정말 이대로 거의 따라
갔다.

이름도 정했다. Deepcuts는 비주류 뉘앙스가 강해서 뺐고, Dighaus →
Diggershaus로 굴려보다가 결국 도메인은 dig.haus. Cloudflare에서
샀고, Claude Code 웹 버전으로 옮겨가서 첫 프로토타입 (앨범 그리드 +
앨범 상세 페이지)을 거기서 뽑았다. 이때까지는 git에도 안 올렸다.
그냥 클로드한테 "만들어달라" 한 번에 다 나왔다.

오늘이 가장 결정이 많이 된 날이었던 것 같다. 코드는 안 짰는데.

감소**. 이때부터 비용이 진짜로 안 무서워졌다.

이날 한국어 정규화 (`normaliseKoreanTerms`)도 처음 만들었다. Claude가

응시" → "슈게이즈". 메탈 커뮤니티는 진짜로 이렇게 부른다. 기계 번역
티가 나면 안 된다.
